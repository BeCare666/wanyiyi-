Fichiers dérivés des polices variables de google/fonts : axe de graisse limité aux graisses utilisées,
sous-ensemble de caractères couvrant le français, l'anglais et le yoruba (Latin, Latin étendu,
diacritiques combinants U+0300-036F, Latin Extended Additional U+1E00-1EFF).
Fonctions OpenType conservées : ccmp, locl, mark, mkmk, kern, liga, calt (Montserrat : toutes).

Polices écartées après vérification :
- Jost : ne contient pas ẹ, ọ, ṣ.
- Cormorant Garamond : accents mal placés au rendu (ô, ù, é), y compris dans le fichier d'origine.
